# Kit evidence

Side-by-side pairs, diffs, and `checklist.tsv` from an iOS simulator capture of the hand-written kit. The capture scale is 1, so a point is a pixel. Transparent design pixels are composited onto the theme background before the pair.

The checklist measures the master frame. `OVER` means a capture edge is more than 2 design pixels from that frame. This run is `OVER 0`.
